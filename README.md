# Alumify

Connect. Learn. Grow.

Alumify is an alumni mentorship platform that connects college students with verified alumni for career guidance, resume reviews, skill development, and professional networking.

## Features
- Student and alumni profiles
- Alumni search and filtering
- Personalized, rule-based mentor matching
- Mentorship requests and status tracking
- Role-based dashboards

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database & Authentication: Supabase

## Getting Started
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure environment variables in `.env`.
4. Start the development server using `npm run dev`.

## Vision
To make alumni connections accessible and turn college networks into meaningful career opportunities.
